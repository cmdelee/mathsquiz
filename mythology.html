Before you start: how this is marked

These questions don't have one fixed correct wording, so instead of matching what's typed against a list of accepted answers, each answer is sent to an AI (Claude, using the API key entered on the Parents / Admin page) along with the question and a short rubric of what a good answer should cover. It reads the answer and marks it correct, partly there, or not quite — the same way a person marking it would, just automatically.

What's actually sent: the question text, the marking rubric, and whatever's typed into the answer box — nothing else about you or the device. It goes straight from this browser to Anthropic's API (the company that makes Claude), not through any server run by this app.

This explanation only appears once, on this device — every question here carries a small "AI-marked" badge afterwards as an ongoing reminder that it works this way.
