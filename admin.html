AI marking

Some question types are free-text, with no single right wording, so they can't be marked by matching against a list of accepted answers. Setting this up lets them be marked by AI instead. It currently powers the standalone Trivia page (Greek Mythology, Harry Potter and Stranger Things), and is written to cover any future AI-marked subject the same way — until a key's set up here, those questions simply stay unavailable.

How it works, and what's sent

When she submits an answer to one of these questions, the question text, a short marking rubric (written for that question, not a real exam) and whatever she's typed are sent straight from her browser to the AI provider chosen below — nothing else about her or the device. Nothing is sent anywhere, ever, unless a key is set up here. The API key is stored only in this browser's local storage, the same as everything else on this page — it is never sent anywhere except to that provider, and it's deliberately left out of the backup file below, so it needs re-entering after a restore.

Only Claude (Anthropic) is offered right now, because it's the only option that's actually workable for a page like this: it can be called directly from the browser with no server in between, and Anthropic's terms don't rule out use by children the way some others do. Google's Gemini is excluded outright — its API terms say it must not be used in an app "directed towards or is likely to be accessed by individuals under the age of 18". Microsoft Copilot doesn't offer an individual API key to use here at all. ChatGPT/OpenAI could work in principle, but its API blocks being called directly from a browser and would need a small backend server built first — not done yet, so it isn't offered below.

Backup and reset

Everything on this page lives only in this browser, on this device — there's no account and nothing syncs anywhere. A backup file is the only way to move it to a new device, or get it back if this device's storage is ever cleared.

Backup

Restore

Replaces everything currently on this device with what's in the chosen backup file.

Reset everything
