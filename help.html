Maths quiz

maths-quiz.html

Long multiplication, long division, long subtraction and long addition, roughly evenly mixed, set at Year 6–7 level. Division always divides exactly (no remainders); subtraction can land on a negative answer; addition always stays positive. Not sure how to actually work out the long multiplication or division questions? See the step-by-step How to: long multiplication & division guide.

It's not a fixed set of questions — it keeps going, including retrying whichever type was just got wrong, until a target number of correct answers is reached: 10 on a school holiday, 25 in term time by default, worked out automatically from the school's own published term dates. Both numbers can be changed from Parents / Admin.

Each of the four operation types has its own difficulty level that rises after a run of correct answers and drops straight back down after a wrong one, so it settles near whatever's challenging-but-doable and climbs gradually over weeks.

Practice exam (11+ entry test)

entry-test.html

Practises the format of an FSCE-run Year 7 entry test used by several grammar and independent schools, plus a separate non-verbal reasoning option for schools whose own test includes that. Every question here is original, written in the same style — none of it is the real test, which stays confidential to FSCE (check whichever school's own familiarisation guide for genuine examples).

The two main papers

  • Adventure — multiple choice: short reading passages with comprehension questions, vocabulary/synonym questions, and maths reasoning word problems.
  • Beacon — short written answers: spelling (a word shown with some letters filled in, like COM____, and only the missing letters need typing) and multi-step maths word problems.

Practice modes

  • Adventure / Beacon — one paper on its own.
  • NVR practice — non-verbal reasoning: figure sequences and odd-one-out puzzles. A separate skill from Adventure/Beacon, not mixed in with them.
  • Mixed practice — a longer session blending Adventure and Beacon together.
  • Focus practice — weighted toward whichever of maths or English has the lower accuracy so far (once there's enough history to tell), so practice leans toward whatever needs it most.
  • Spaced review — a dedicated session of whatever's currently due for review: still-shaky questions, and older correct ones worth checking have actually stuck. A question that slips after being learned gets flagged as "Slipping back" on the Progress page.
  • Mock exam — a longer, timed session (20 minutes / 20 questions by default, both changeable from Parents / Admin) blending Adventure and Beacon, finishing automatically if time runs out.

Sessions aren't a plain shuffle — each question is remembered as last answered right or wrong, and a weighted draw favours recently-missed questions over ones never seen, and both over ones already answered correctly, so nothing is guaranteed or excluded but practice still leans toward what needs it.

Trivia

mythology.html

A standalone page, just for fun and not linked to the 11+ practice or the Progress page — it keeps its own history and progress, shown on the page itself. Four subjects: Greek Mythology, Harry Potter, Stranger Things and Red Dwarf, each written true to its own source material's actual tone rather than a softened version of it.

Each session is 25 random questions from the chosen subject's own pool — mostly quick multiple-choice and single-word questions, matched and marked instantly on this device, plus up to 5 longer free-text questions once AI marking's set up (see below). A session always includes at least one of whichever kinds are available, and never more than 5 long-answer questions, so it's quick to get through rather than mostly slow, effortful free-text marking.

The long, free-text questions don't have one single correct wording, so they're marked on a small scheme — one mark for each point a good answer should cover, up to that question's own total (2–5 marks, shown as a badge on the question). Multiple-choice and quick-answer questions are always worth a flat 1 mark. A parent can hide any subject entirely from the picker in Parents / Admin, without losing its saved history.

Without an AI marking key set up, the long-answer questions are simply left out of sessions — everything else works the same either way.

How AI marking works, and privacy

Set up from Parents / Admin

Most questions across the app — multiple-choice, short spelling/word answers — have one or more fixed correct answers, so they're checked and marked instantly on this device. Nothing about those is ever sent anywhere.

Trivia's long, free-text questions are different: there's no single "correct" wording to match against, so each one is marked by sending it to Claude (Anthropic's AI) instead. What's actually sent: the question text, a short marking rubric written for that question (not a real exam), and whatever's been typed into the answer box — nothing else about the device or whoever's using it. It goes straight from this browser to Anthropic's API, not through any server run by this app. It comes back with a mark out of that question's own total and a line of feedback explaining what earned or missed a mark.

Nothing is sent anywhere, ever, unless an API key's been set up in Parents / Admin first — without one, Trivia's long-answer questions are simply left out of sessions, and everything else keeps working exactly the same. The key itself is stored only in this browser's local storage, the same as everything else in the app; it's never sent anywhere except to Anthropic, and it's deliberately left out of the downloadable backup, so it needs re-entering after a restore.

Only Claude is offered as a provider, because it's the only one that's actually workable here: it can be called directly from the browser with no server needed in between, and Anthropic's terms don't rule out use by children the way some others do. Google's Gemini is excluded outright — its API terms say it must not be used in an app "directed towards or is likely to be accessed by individuals under the age of 18". Microsoft Copilot doesn't offer an individual API key at all. ChatGPT/OpenAI could work in principle, but its API blocks being called directly from a browser and would need a small backend server built first — not done here.

A get-started key can be created at console.anthropic.com. Each long-answer question marked costs a small fraction of a cent against that key's own balance; multiple-choice/quick-answer questions and everything in the maths and entry-test apps cost nothing, since nothing is ever sent for those.

Progress page

stats.html

A read-only page showing scores, streaks and history for the maths and entry-test apps — nothing on it can be changed or reset. Behind the same parent PIN as Parents / Admin by default, though a parent can turn that off so progress can be checked without asking each time. Trivia keeps its own separate progress summary on its own page rather than appearing here.

Parents / Admin

admin.html

One PIN-locked page covering settings and resets for everything: maths targets and streak settings, the entry test's exam date/mock exam/session-size settings, the AI marking key and which Trivia subjects are offered, whether the Progress page needs the PIN, backup/restore of everything as one file, and a full reset. The PIN itself is chosen the first time the page is opened on a device — only its hash is ever stored, never the PIN itself.

Installing on a phone or tablet

This is a Progressive Web App, so it installs straight from the browser — no app store needed.

iPhone / iPad

Open the site in Safari (it has to be Safari — Chrome and other browsers on iOS can't do this), tap the Share icon, then "Add to Home Screen".

Android

Open the site in Chrome, then use "Add to Home Screen" or "Install app" from the ⋮ menu — it's sometimes also offered as a banner automatically.

Either way, it then opens as its own icon without any browser address bar, and keeps working offline once it's been opened at least once. Everything — history, PIN, targets, the AI marking key — lives only in that one browser on that one device; there's no account and nothing syncs anywhere, so using a different browser or reinstalling starts with a clean slate (see Parents / Admin for backing that up to a file first).
