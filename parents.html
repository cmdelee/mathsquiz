            Backup and reset

            Everything on this page lives only in this browser, on this device — there's no account and nothing syncs anywhere. A backup file is the only way to move it to a new device, or get it back if this device's storage is ever cleared.

            Backup

            Downloads everything — names, targets, streak settings and history for both apps — as one file you can keep somewhere safe.

            Restore

            Replaces everything currently on this device with what's in the chosen backup file.

            Reset everything

            Wipes all settings and history for both apps on this device, back to a completely fresh start. This can't be undone — take a backup first if there's any chance you'll want any of it back.
